A modern and responsive SaaS landing page built with Next.js, TypeScript, and Tailwind CSS.

This project was created as part of my frontend portfolio, with a strong focus on clean UI design, reusable components, responsiveness, accessibility, and modern development practices.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/BEmanuel87/taskflow-saas-landing-page.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
